# Privacy Policy for Rep Ring

Last updated: 2026-11-05

Rep Ring is a standalone Apple Watch application.

Rep Ring **does not collect, transmit, store or share any personal information, workout data or user data**.
All counting data is stored locally only on your Apple Watch.
There are no analytics, no tracking, no network requests made by this app.
